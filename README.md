# Duel Doctrine Lab: TEST builds

This repository hosts **TEST builds** of Duel Doctrine Lab, a personal Yu-Gi-Oh practice app. It is **not the release** and not a supported site. Builds here may be unfinished, may change or disappear without notice, and are published for testing only.

- Each build lives in its own folder (for example `/r17/`) and is the built static app only.
- No lab source, gate files or credentials are stored here.
- The duel engine is EDOPro / ygopro-core via ocgcore-wasm (AGPL-3.0); its source is offered in each build as `engine-source.zip`, with licences in `licenses/`.
- Not affiliated with Konami. Yu-Gi-Oh names and card imagery belong to their respective owners.
